# Prime Star Quiro

Static one-page website for Prime Star Quiro, a chiropractic clinic on Avenida Sapopemba (Jardim Adutora, São Paulo). This is a copy of the site published at primestarquiro.netlify.app.

## Technologies
- Plain HTML, CSS and vanilla JavaScript (no build step)
- Google Fonts (Cormorant Garamond, Figtree)
- Netlify static hosting

## Running locally
Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
# or
netlify dev
```

## Structure
- `index.html` – the full page
- `css/styles.css` – styles
- `js/main.js` – interactions and the `CONFIG` object (e.g. `modoDemonstracao` toggles the demo banner)
- `assets/` – favicon (add `mariana.jpg` here to replace the photo placeholder)
